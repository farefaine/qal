# artifacts/tokenizers/

Saved tokenizer artifacts.

| Location | Produced By | Purpose |
|---|---|---|
| `tigrinya_tokenizer_{8k,16k,32k}.json` | `tokenization/hf_bpe/` | Hugging Face tokenizer artifacts saved directly in this directory by the current presets |
| `from_scratch/` | `tokenization/from_scratch/` | Educational/from-scratch tokenizer artifacts |

Output paths are configured in `config/tokenizer/`. The current presets do not write into `hf_bpe/`.
